# ADR 0006: 实时数据走工具，RAG 只承载稳定知识

日期：2026-09-19　状态：已接受

## 背景

订单状态、物流轨迹、发票、案例状态是**易变事实**。如果把它们写进知识索引：

1. 数据在入索引那一刻就开始过期，而 RAG 管道对"这条证据多老了"没有概念；
2. 过期数据会被**自信地引用**——引用校验只保证"答案来自证据"，不保证证据本身
   是当前的；
3. 客户问"我的订单到哪了"，索引里的样例数据可能碰巧匹配，产出一个与该客户无关
   的确定答案。

## 决策

易变事实**只**通过 Tool Gateway 的读类工具实时获取（`order.get_status`、
`shipment.track`、`billing.get_invoice`、`case.read`）；RAG 语料只承载稳定知识
（政策、流程、规格）。意图层已把"实时数据问题"识别为 `BUSINESS_READ` 路由，
orchestrator 对该路由**先试工具、绝不检索**。

## 后果

- 工具不可用时的正确行为是**弃权转人工**（`TOOL_*` 原因码），不是降级到知识问答
  ——错误数据比没有数据更贵。
- 工具回执是第二类证据：引用的 `source_uri` 形如 `tool://order.get_status/88123`，
  `document_version_id` 为空（迁移 0036），审计中与文档引用可区分。
- 数据摄入侧禁止把易变实体（订单表、物流事件流）灌入知识空间；knowledge_manager
  角色的文档上传入口应拒绝此类来源（后续可在上传校验中加提示）。

## 未决

- 读工具的 tenant 级缓存窗口（同一订单 60 秒内重复查询是否复用回执）留待成本
  数据（Phase 5.1）证明需要时再做。
