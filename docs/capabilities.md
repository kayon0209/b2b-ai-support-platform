# 能力矩阵

范围：当前仓库实现。功能存在不代表已为某家企业配置，部署证据按 [生产接入条件](production-readiness.md) 管理。

## 核心产品

| 能力 | 当前实现 | 接入条件与边界 |
|---|---|---|
| 客户网页客服 | `/` 首页、`/support` 访客会话、时间线、转人工、结束、新会话、解决反馈与 CSAT | 企业链接携带租户标识；业务数据读取需要身份与记录归属校验；回复通过轮询获取，不是逐字流式输出 |
| 坐席工作台 | 会话优先队列、认领、转接、退回、人工回复、历史分页、搜索、草稿、常用话术 | 坐席目录与会员身份须对应；租约控制发送权；关闭会话不等于解决工单 |
| AI 副驾 | 异步建议回复/摘要、来源轮次、插入/追加/替换草稿、过期结果拦截 | 租户开关与模型配置控制；草稿由坐席确认发送，不能自动代替坐席回复 |
| 工单与 SLA | 生命周期、分配、升级、策略、附件证据 | 附件保存为工单证据，不是客户聊天文件投递 |
| 运营管理 | 客户、知识、Prompt、开关、渠道连接器、审批、质量、实验、坐席、成员、用量与品牌页面 | 页面操作仍受服务端权限和租户隔离控制 |

## AI 与业务流程

| 能力 | 当前实现 | 边界 |
|---|---|---|
| 知识回答 | 版本化摄取，tenant/ACL 预过滤，FTS/向量/trigram/别名检索，RRF 与可选重排，引用校验 | 只检索有效、授权版本；相似度不是事实置信度；缺证据时澄清、拒答或转人工 |
| 路由与语义增强 | 基础规则路由；受模式与租户开关控制的影子分析、辅助建议、语义只读路径 | 模型输出不能绕过规则红线、工具权限或人工租约 |
| 多意图任务 | 持久化规划、补参、依赖、受控工具绑定、回执驱动状态、人工对账 | 工具风险、schema、归属或条件不确定时停止推进；不是自由 SQL/HTTP Agent |
| 业务查询 | `order.get_status`、`shipment.track`、`billing.get_invoice`、`inventory.check_stock`、`case.read` | 前四项经租户业务 API；内部 Case 从平台读取；Demo 数据仅限 local/test |
| 业务写入 | Gateway 提案、确认、实时检查、幂等、持久执行意图、后置验证、审计 | 以租户实际解析到的执行器为准；未知结果人工对账，不盲目重放 |
| 标准服务流程 | 订单进度、质量受理、发票申请、制造/技术升级 | 模板与实例受开关控制；查询或内部 Case 不代表已完成维修、开票或外部系统更新 |
| 售前资料与商机 | 产品/库存/报价来源契约；local/test 合成售前资料与 `demo_crm` 商机闭环 | 不表示真实 CRM 商机写入已交付；示例报价不是客户报价 |
| 知识发布 | 候选暂存、固定集评测、签名证据、审批、激活、发布后检查与回滚路径 | 需要获批数据集、签名配置、执行预算和租户开关；与 Prompt 的外部 CI provenance 不同 |
| 质量运营 | 引用/拒答评测、客户结果事件、风险分层人工复核、Prompt promotion 与受控 A/B | 合成分数不是实际客户解决率；无回复不算解决；默认阈值需业务校准 |

## 安全与可靠性

- PostgreSQL RLS 与应用层 tenant 条件；运行角色和迁移凭据分离。
- 请求、提案、执行、确认和人工租约的权限/版本检查。
- Inbox/Outbox、陈旧 claim 回收、执行预算、失败重跑、幂等与 UNKNOWN 对账。
- 私有对象存储、短时签名访问、格式检查、扫描状态与保留/清理机制。
- `/healthz` 存活、`/readyz` 数据库就绪、API/Worker 指标、告警规则和追踪配置。
- API 多阶段镜像包含前端；Compose 用于本地开发，Kubernetes 清单表达部署拓扑。

## 明确边界

当前没有通用全渠道适配、客户聊天文件投递、通用外部动作撤销或完整跨渠道身份合并。合规导出覆盖 audit/cases；完整附件字节与客户记录导出需要单独定义法律和产品范围。文件格式检查不是完整恶意软件扫描；相关要求见 [安全文档](security.md)。

上述能力范围对应 `apps/admin-web/src/pages/`、`platform_core/agent_runtime/`、`tool_gateway/`、`integrations/`、`identity/`、`knowledge/` 和 `apps/worker/src/worker/`。本表不引入新的生产通过声明。
