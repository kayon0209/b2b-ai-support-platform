## 完成状态口径

- **代码可合入**：实现、迁移、契约、安全与 UI/UX 检查通过；模型能力可以保持关闭。真实模型未测必须注明。
- **语义能力可灰度**：满足真实模型质量、成本、延迟与降级门禁，并记录获准租户和可用工具。
- **生产可放量**：还需真实身份源、渠道投递、存储、业务连接器、生产拓扑与容量验收。
- WorkBuddy 的“完成”表示待 Codex 验收；验收状态使用“通过 / 失败 / 阻塞 / 未执行 / 经批准不适用”。
- 上轮允许合并的性能例外只适用于当时变更，不能视为后续性能或生产发布豁免。

## 文件交付约定

WorkBuddy 将开发说明、迁移/回滚指引与最终状态更新在本目录；验收输出放到新建的
`docs/implementation/ai-support-v2/evidence/<commit>/`。该目录只提交脱敏摘要、命令、环境指纹和允许公开的截图；原始日志、客户消息、密钥、数据库快照和模型原始输出不进 Git。

实施中如需改变契约，先在本执行包记录差异及理由，再同步实现、测试和客户端；不得只改代码使任务单失真。
