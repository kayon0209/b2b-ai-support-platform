# Pinned dependency manifest for the B2B AI support platform.
#
# This file exists because the project previously declared its runtime
# dependencies nowhere: they were installed ad hoc into .venv, and when that
# environment was damaged there was no way to reconstruct it. Everything the
# API, worker and test suite import is listed here so a fresh checkout is
# reproducible with two commands:
#
#   python -m venv .venv
#   .venv/Scripts/python -m pip install -r requirements-dev.txt   # Windows
#   .venv/bin/python   -m pip install -r requirements-dev.txt     # POSIX
#
# Ranges rather than exact pins: this is a pre-1.0 platform and the locks are
# maintained by the CI image, not here. Lower bounds are the versions the
# suite was actually verified against (see .workbuddy-ai/memory/).
