# Development and verification dependencies.
#
# Runtime dependencies live in `requirements.txt` and are included here, so a
# fresh checkout is reproducible with two commands:
#
#   python -m venv .venv
#   .venv/Scripts/python -m pip install -r requirements-dev.txt   # Windows
#   .venv/bin/python   -m pip install -r requirements-dev.txt     # POSIX
#
# Splitting the two matters: the API image installs `requirements.txt` only, so
# no test framework is in the runtime image, and a package added for the
# application lands in both places rather than in whichever list the author
# happened to remember.

-r requirements.txt
