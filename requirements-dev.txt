# Development and verification dependencies.
#
# Runtime dependencies live in `requirements.txt` and are included here, so a
# fresh checkout is reproducible with two commands:
#
#   python -m venv .venv
#   .venv/Scripts/python -m pip install -r requirements-dev.txt   # Windows
#   .venv/bin/python   -m pip install -r requirements-dev.txt     # POSIX
#
# Splitting the two matters: the API image installs `requirements.txt` only, so
# no test framework is in the runtime image, and a package added for the
# application lands in both places rather than in whichever list the author
# happened to remember.

-r requirements.txt

# --- Development and verification ------------------------------------------
pytest>=8.3
pytest-asyncio>=0.24
# The tool_gateway unit suite runs against an in-memory async SQLite engine,
# so the aiosqlite driver is a test-time requirement, not an optional extra.
aiosqlite>=0.20
# Pinned to the ruff the tree is actually linted and formatted with. The
# previous pin (>=0.8,<0.9) predated the formatter's stable style change, so CI
# disagreed with every local run; verified 2026-09-23 that 0.16.8 passes both
# `ruff check` and `ruff format --check` over the whole CI scope.
ruff>=0.16,<0.17
mypy>=1.13
detect-secrets>=1.5
